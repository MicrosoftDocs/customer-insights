# Permission changes in the May 2026 release (version 1.1.65002.146)

This article details the permission changes introduced in the **May 2026 release (version 1.1.65002.146)** for the out-of-the-box roles in Customer Insights - Journeys. For background on how to use this changelist to keep custom roles in sync, see [Permission changes in each release](role-permissions.md).

The May 2026 release didn't change any out-of-the-box role permissions or privileges.
